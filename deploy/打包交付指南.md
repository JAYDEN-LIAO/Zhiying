# 智影 · 打包交付指南（打包方用）

> 目标：从 SVN `AI_Ying_TestVersion/trunk/v<版本>/` 的打包材料，编译出最终安装包 exe。
> 材料目录 = 安装器完整输入集，**zhiying.iss 已就位，无需任何补文件**。

---

## 一、准备

1. 一台 Windows 10/11 机器
2. 安装 **Inno Setup 6**（本材料基于 6.2.1 定版，6.3+ 亦可）：https://jrsoftware.org/isdl.php

## 二、取材料

SVN 检出或导出（推荐 export，干净）：

```
svn export https://10.0.0.233/svn/AI_Ying_TestVersion/trunk/v0.90 C:\ZhiyingPack\v0.90
```

（账号密码向管理员获取；首次连接证书告警选「永久接受」）

得到目录结构（**不要改名、不要移动任何文件**）：

```
v0.90\
├── zhiying.iss          ← 安装器脚本（编译入口）
├── dist\智影桌面端\      ← 壳 exe + _internal（后端字节码，无明文源码）
├── frontend-desktop\dist\
├── config\  deploy\  desktop\  requirements.txt
```

## 三、编译安装包

**方式 A（图形界面）**：双击 `v0.90\zhiying.iss` → Inno Setup 打开 → 菜单 **Build → Compile**（或 F9）

**方式 B（命令行）**：

```
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" C:\ZhiyingPack\v0.90\zhiying.iss
```

产物在材料目录内的 `build\` 下：

```
v0.90\build\视频快速智能检索平台 Ver 0.90.exe     ← 最终安装包
```

**收尾：对该 exe 做代码签名**（签名后交付/分发）。

> 说明：版本号已写在脚本内（0.90），GUI 直编即可，无需传参；
> 编译期几秒钟~1 分钟（33MB 材料压缩）；编译会弹几个语言包 Warning，无害忽略。

## 四、安装包用户侧交互流程（知情参考）

安装包为**一体化安装**：向导 + 环境安装（Python 依赖 + 内嵌 PostgreSQL + 25GB 模型）全部在安装段内完成，装完即可用。

| 步骤 | 用户看到 / 操作 |
|---|---|
| 1 选目录 | 默认 `D:\Zhiying`；自动预检磁盘 ≥40GB，不足会提示 |
| 2 模型来源 | 三选一：<br>**8B（推荐默认）**— 在线下载，4096 维，需 ~16GB 显存<br>**2B（低显存）**— 在线下载，2048 维<br>**自备模型导入** — 点「浏览…」选 models 目录（必须含 `Qwen\` 子目录，如 `D:\models`）；选完 robocopy 复制约 25GB 进安装目录，源目录不动 |
| 3 代理 | 预填 `http://127.0.0.1:`，**补上端口即可**（如 7897）；直连/国内网络可整体清空留空 |
| 4 桌面图标 | 可勾选（默认状态照常） |
| 5 安装 | 复制文件后自动进入「正在安装运行环境」，单进度条 + 阶段文字：<br>安装 Python/FFmpeg → 装依赖（最耗时）→ 内嵌 PostgreSQL → **下载模型（25GB，占大头）** → 配置 → 初始化数据库 → 完成<br>条会蠕动平滑属正常；**请勿中途关机断网** |
| 6 完成 | 快捷方式在环境装完后才创建；可直接勾选启动 |

## 五、异常与排查

| 现象 | 处理 |
|---|---|
| 进度条长时间不动 | 30 分钟无任何新输出才会判卡死弹窗；模型下载段慢是正常（25GB），看任务管理器网络占用确认在动 |
| 弹「环境安装失败」 | 弹窗内有日志头部；完整日志在 `<安装目录>\vendor\install.output`（与 install.log）。常见原因：网络不通 / 磁盘满 / 代理端口错 |
| 弹「无法启动（powershell 启动失败）」 | 安全软件拦截——把安装目录加入白名单重装 |
| 装到一半中断 | **直接重新运行安装包**即可从断点续传（模型下载支持续传） |
| 卸载 | 控制面板卸载：自动停服务、清环境；**用户数据（data）与自备模型（models）保留** |

## 六、版本更新流程（下次发版）

开发侧 bump 新版本 → 重新出货 → SVN `TestVersion/trunk/` 下出现新目录 `v<新版本>/`。
打包方：对新目录重复「二、三」两步即可，与旧版本互不影响。
