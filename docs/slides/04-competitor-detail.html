其他竞品速览

🔧 Mixpeek 架构最接近的开源参考 pipeline 路线

多模态提取 pipeline（Whisper + CLIP/SigLIP + Gemini VLM）+ 多阶段检索（RRF/DBSF/加权融合）。与 Cerno 3 路编码思路高度相似。核心差异：Mixpeek 用通用图像嵌入 + 外部 API 做 VLM，Cerno 用视频原生嵌入 + 本地 GPU。

→ Mixpeek 证明了 pipeline 路线可行；Cerno 的改进方向是去 API 依赖和视频原生编码

🤖 VideoDB Agent-first Agent 驱动

「视频即数据」理念，See-Understand-Act 循环。2026 年推出 Director 开源框架（20+ 预置 video agents）和 Agentic Streams——Agent 自主完成检索、剪辑、配音、翻译。收购 Devzery 强化开发者工具链。

→ 与 Cerno 声明式 DAG 不同哲学：Agent 灵活但不可预测，声明式可控但灵活度较低。目标殊途同归

📦 txtai 通用框架 Apache 2.0

Apache 2.0 开源全能型 AI 框架。视频能力仅为多模态延伸——all-MiniLM-L6-v2（384 维）通用嵌入 + BLIP 图像字幕，缺乏场景分割、1fps 帧编码、滑动窗口 chunk 等视频专项设计。

→ 证明了"通用框架套视频"行不通——视频需要原生嵌入 + 场景分割 + 时序建模的专项优化
