两套方案 — 按 GPU 配置选择

方案 A：27B Dense 高分方案
82.8 Video-MME
27B 全部激活
~16GB INT4 显存

优势：分数最高（82.8），Dense 架构推理延迟稳定，社区生态成熟，HF 上 fine-tune 版本丰富。

代价：~16GB 占掉大部分显存，同一张卡很难再加载 Embedding 模型（~16GB）。需要双卡或多卡分离部署 VLM 和 Embedding。

适合：拥有 48GB+ 显存（A6000 / 双卡 4090）的配置，追求极致单模型质量。

方案 B：35B MoE（推荐默认） 单卡最优
82.5 Video-MME
35B/3B MoE 激活
~8GB INT4 显存

优势：MoE 3B 激活仅占 ~8GB，留出 ~16GB 在同卡加载 Embedding 模型（VLM 8GB + Emb 16GB = 24GB 刚好装满）。82.5 vs 82.8 的 0.3 分差在 benchmark 噪声范围内。

代价：MoE 推理延迟略高于同激活参数的 Dense 模型（约 +10%），社区 fine-tune 版本不如 Dense 丰富。

适合：单卡 RTX 4090（24GB）标准配置，VLM + Embedding 串行执行刚好装满。

💡
两个模型质量几乎等同（82.8 vs 82.5，差 0.3 分）。选择取决于硬件：单卡 4090 推荐 MoE 方案（VLM+Embedding 一卡搞定）；双卡或 48GB+ 可选 Dense 方案（追求极致单模型质量）。Cerno 默认走 MoE 方案。
