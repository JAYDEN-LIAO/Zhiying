二、 Docker 基础配置代码
根据《最终可行方案》与《数据字典》，系统强依赖 PostgreSQL 17 + pgvector 0.8 扩展，且运行环境中必须包含 FFmpeg 用于音频流抽取与 1fps 内存抽帧。以下是完美对齐规范的基础设施配置：

1. docker-compose.yaml (基础设施编排)
设计对齐说明：将 PostgreSQL 的 5432 端口直接映射至宿主机，确保你无论是直接在宿主机本地调试运行 FastAPI，还是将其打包进 Docker，都能通过 localhost:5432 严丝合缝地连接到数据库。

YAML
version: '3.8'

services:
  db:
    image: pgvector/pgvector:17-pgvector  # 严格对齐规范：PostgreSQL 17 + pgvector 0.8
    container_name: cerno_postgres
    environment:
      POSTGRES_USER: cerno
      POSTGRES_PASSWORD: cerno
      POSTGRES_DB: cerno
    ports:
      - "5432:5432"                       # 映射至宿主机，对齐 localhost:5432 契约
    volumes:
      - cerno_db_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U cerno -d cerno"]
      interval: 5s
      timeout: 5s
      retries: 5
    networks:
      - cerno_network

  app:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: cerno_app
    ports:
      - "8000:8000"
    environment:
      - POSTGRES_URI=postgresql+asyncpg://cerno:cerno@db:5432/cerno  # 容器间通信使用 db 服务名
    volumes:
      - .:/home/cerno/project
      - /home/cerno/data:/home/cerno/data  # 挂载视频数据存放目录
    depends_on:
      db:
        condition: service_healthy
    networks:
      - cerno_network

volumes:
  cerno_db_data:

networks:
  cerno_network:
    driver: bridge
2. Dockerfile (应用镜像定义)
设计对齐说明：由于 Pipeline 涉及 FFmpeg 的深度调用，基础镜像选用包含了完整编译工具链和 FFmpeg 环境的官方 Python 镜像。

Dockerfile
FROM python:3.12-slim

# 设置工作目录

    ffmpeg \
    gcc \

# 复制项目代码

# 暴露 FastAPI 默认服务的 8000 端口

💻 1.1 开发提示词（Coding Agent）
Plaintext
角色：资深 Python 后端架构师（精通 SQLAlchemy 2.0 异步模式与 PostgreSQL 17 高级特性）

任务：请根据以下技术规范，编写 Cerno 系统的数据库基础配置定义文件 `core/db.py` 和 ORM 模型定义文件 `core/models.py`。代码必须严格遵循 SQLAlchemy 2.0 的 Mapped 语法，并且完全契合指定的字段名、数据类型和索引策略。

技术要求：
1. 【数据库连接】：
   - 文件路径：`core/db.py`
   - 使用异步引擎 `create_async_engine` 连接数据库：`postgresql+asyncpg://cerno:cerno@localhost:5432/cerno`
   - 线程池配置：`pool_size=20`，`max_overflow=10`，`echo=False`
   - 会话配置：使用 `async_sessionmaker` 创建 `AsyncSessionLocal`，设置 `expire_on_commit=False`
   - 定义声明式基类 `class Base(DeclarativeBase): metadata = MetaData(schema="public")`

2. 【扩展与触发器函数初始化】：
   - 在 `core/db.py` 中实现异步初始化函数 `async def init_db()`。
   - 使用原始 SQL 异步执行创建三个扩展：`CREATE EXTENSION IF NOT EXISTS "uuid-ossp";`, `CREATE EXTENSION IF NOT EXISTS "pg_trgm";`, `CREATE EXTENSION IF NOT EXISTS "vector";`
   - 异步执行创建 `scenes_search_vector_update` 触发器函数，用于自动维护全文检索：
     NEW.search_vector 必须组合自：caption (权重 'A') + ocr_text (权重 'B') + aligned_transcript (权重 'C')，均使用 'simple' 配置及 coalesce 处理空值。
   - 在执行完毕 raw SQL 扩展和函数定义后，调用 `await conn.run_sync(Base.metadata.create_all)`。

3. 【ORM 数据模型】：
   - 文件路径：`core/models.py`
   - 严格导入 `from pgvector.sqlalchemy import Vector`
   - 定义原生的 Python 枚举类并绑定到 SQLAlchemy Enum：
     - `VideoStatus`: pending, processing, completed, failed
     - `PresetMode`: quick, standard, full, custom
     - `ContentType`: general, meeting, surveillance, product
   - 定义 `Video` 模型（表名 `videos`）：
     - 包含主键 `id` (UUID, 默认 uuid.uuid4), `status` (VideoStatus, 默认 PENDING, 带索引), `progress` (Float, 默认 0.0), `error_message` (Text, 可空)。
     - 文件信息：`file_path` (String(1024)), `file_name` (String(512)), `file_size` (Integer), `duration` (Float, 可空)。
     - 配置字段：`preset` (PresetMode), `content_type` (ContentType), `language` (String(16), 默认 "auto")。
     - 6个感知开关（全部为 Boolean, 默认值按规范）：`audio_enabled`(True), `vision_enabled`(True), `ocr_enabled`(True), `grounding_enabled`(False), `caption_enabled`(True), `summary_enabled`(True)。
     - JSONB 字段：`qc_result` (JSONB, 可空), `summary` (JSONB, 可空)。
     - 时间戳：`created_at` (DateTime(timezone=True), 默认 utcnow), `updated_at` (DateTime(timezone=True), 默认 utcnow, onupdate=utcnow)。
     - 关联关系：`scenes` (一对多关系, 级联删除 `cascade="all, delete-orphan"`), `transcript` (一对一关系, `uselist=False`, 级联删除)。
   - 定义 `Scene` 模型（表名 `scenes`）：
     - 主键 `id` (Integer, 自增), 外键 `video_id` (UUID, 关联 `videos.id`, 级联删除 `ondelete="CASCADE"`, 带索引)。
     - `scene_index` (Integer), `start_sec` (Float), `end_sec` (Float), `keyframe_path` (String(1024), 可空)。
     - 向量字段：`embedding` (Mapped[list[float] | None]), 使用 `Vector(768)` 类型。
     - 文本字段：`ocr_text` (Text, 可空), `aligned_transcript` (Text, 可空), `caption` (Text, 可空), `prev_caption` (Text, 可空)。
     - 实体字段：`entities` (JSONB, 可空)。
     - 全文检索字段：`search_vector` 映射为名为 `"tsvector"` 的列，可空。
     - 时间戳：`created_at` (DateTime(timezone=True), 默认 utcnow)。
     - 索引配置（必须在 `__table_args__` 中完整定义）：
       * `Index("idx_scenes_video_scene", "video_id", "scene_index")`
       * `Index("idx_scenes_start_sec", "video_id", "start_sec")`
       * HNSW 向量索引：`Index("idx_scenes_embedding_hnsw", "embedding", postgresql_using="hnsw", postgresql_with={"m": 16, "ef_construction": 200}, postgresql_ops={"embedding": "vector_cosine_ops"})`
       * GIN 全文检索索引：`Index("idx_scenes_search_vector_gin", "search_vector", postgresql_using="gin")`
   - 定义 `Transcript` 模型（表名 `transcripts`）：
     - 主键 `id` (Integer, 自增), 外键 `video_id` (UUID, 关联 `videos.id`, 级联删除, 唯一约束 `unique=True`)。
     - `full_text` (Text, 必填), `words` (JSONB, 可空), `language` (String(16), 可空), `duration_transcribed` (Float, 可空)。
     - 时间戳：`created_at` (DateTime(timezone=True), 默认 utcnow)。
     - 索引配置：`Index("idx_transcripts_full_text_gin", "full_text", postgresql_using="gin", postgresql_ops={"full_text": "gin_trgm_ops"})`

请直接输出完整、无缺失行的代码，严禁包含任何 `// TODO` 或省略。
